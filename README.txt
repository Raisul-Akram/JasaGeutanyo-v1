JASAGEUTANYOU - WEBSITE (versi desain ulang)

Cara menjalankan: ekstrak folder, lalu buka index.html di browser.
Gambar tersimpan lokal di assets/images (internet hanya dipakai untuk Google Fonts).

Yang perlu Anda isi sebelum publikasi (cari di bagian <script> pada index.html):
1. CONFIG.wa     -> nomor WhatsApp resmi JasaGeutanyou untuk pendaftaran mitra (format 62812xxxxxxx).
2. CONFIG.email  -> email kontak (tampil di footer).
3. const P=[...] -> data penyedia jasa. Saat ini DATA CONTOH. Isi properti "wa" tiap mitra
                    dengan nomor asli; selama kosong, tombol WhatsApp menampilkan pemberitahuan.
